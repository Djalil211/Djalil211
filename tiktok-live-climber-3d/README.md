# 🧗🪵 رجل الطريق الخشبي — ثلاثي الأبعاد (Three.js) + بث TikTok

نفس فكرة اللعبة لكن **بمشهد ثلاثي الأبعاد حقيقي** (WebGL/Three.js): رجل سمين مضحك يصعد
سلّماً خشبياً نحو الكأس 🏆، والمركّبات (دراجة 🏍️ / سيارة 🚗 / رياضية 🏎️ / شاحنة 🚚)
تسقط ثلاثية الأبعاد من الأعلى. **أنت تتحكم فيه بالكيبورد ليتفاداها**، والهدايا الحقيقية
من مشاهديك تُسقطها عليه.

> ⚠️ أداة غير رسمية تعتمد على `tiktok-live-connector` (على مسؤوليتك). تتطلب **مفتاح توقيع
> مجاني** من https://www.eulerstream.com.

---

## 🎮 التحكم (كيبورد)
- **← →** أو **A / D** = تحرّك يميناً/يساراً للتفادي
- **↑ / W** = صعود أسرع • **↓ / S** = إبطاء
- في وضع المعاينة يعمل مساعد تفادٍ تلقائي؛ في البث الحقيقي التحكم بيدك.

## 🧩 القصة
الرجل يصعد تلقائياً ← أي **هدية حقيقية** تُسقط عليه مركبة ← إن أصابته يسقط ويعود للصفر ←
إن تفاداها بالكيبورد واصل الصعود ← **بدون أن تُطرحه الهدايا يصل للقمة ويفوز 🏆**.

---

## ✅ المتطلبات
- كمبيوتر + **Node.js 18+**.
- **مفتاح EulerStream مجاني**.
- **TikTok Live Studio / OBS** للبث.
- مكتبة **Three.js مضمّنة** داخل المشروع (لا تحتاج إنترنت لتشغيل المشهد).

---

## 🚀 التشغيل
```bash
npm install        # تنزيل المكتبات (three + tiktok-live-connector + express + ws)
npm start          # تشغيل الأداة
```
افتح `http://localhost:3000/?name=اسمك` ← اضغط **«ابدأ 🎬»** ← اعرضها في TikTok Live Studio/OBS
كـ **Browser Source** (الخلفية شفافة) ← تحكّم بالأسهم لتفادي المركّبات الساقطة بهدايا مشاهديك!

## ⚙️ الإعدادات (`config.json`)
```json
{ "tiktokUsername":"اسمك_بدون_@", "signApiKey":"مفتاحك", "climbSpeed":0.020 }
```

استمتع ببثّ مضحك وتفاعلي ثلاثي الأبعاد! 🎉
