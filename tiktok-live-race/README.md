# 🏁 سباق الدول العربية — أداة بثّ TikTok تفاعلية (هدايا حقيقية)

أداة تعمل على **كمبيوترك** أثناء بثّك المباشر على TikTok. تتصل ببثّك وتجعل
**الهدايا واللايكات والتعليقات الحقيقية** من مشاهديك تحرّك الدول في السباق،
وتعرض لوحة السباق فوق بثّك (عبر TikTok Live Studio أو OBS).

> ⚠️ **تنبيه صادق:**
> - تعتمد الأداة على مكتبة `tiktok-live-connector` وهي ربط **غير رسمي** بـ TikTok (مخالف
>   لشروطهم وقد يوقفه تحديث ما). الاستخدام على **مسؤوليتك الشخصية**.
> - تحتاج **مفتاح توقيع** من خدمة EulerStream (يوجد **باقة مجانية للأبد** — انظر الأسفل).
> - لم أستطع تجربة الاتصال الحقيقي بـ TikTok داخل بيئة التطوير (الشبكة محجوبة)، لكن
>   الكود مكتوب حسب توثيق المكتبة الرسمي v2 ومُختبَر من ناحية الإقلاع وتقديم اللوحة.

---

## 🧩 كيف تعمل؟
1. تشغّل الأداة على كمبيوترك ← تفتح **لوحة سباق** في المتصفح (`http://localhost:3000`).
2. تتصل تلقائياً ببثّك على TikTok (باسم المستخدم الخاص بك).
3. تلتقط هذه اللوحة داخل **TikTok Live Studio** أو **OBS** وتبثّها فوق كاميرتك.
4. أي مُشاهد:
   - **يكتب اسم دولة** في التعليقات ← تندفع تلك الدولة. 🇩🇿🇲🇦🇪🇬…
   - **يُرسل لايك** ← يزيد حماس السباق. ❤️
   - **يُرسل هدية** ← دفعة كبيرة + عرض الهدية باسمه وقيمتها. 🎁💎
5. أول دولة تصل للنهاية تفوز 🏆 (تُعاد الجولة تلقائياً كل 9 ثوانٍ لبثّ مستمر).
6. **الهدايا تصل إلى حسابك عبر TikTok كالمعتاد** — اللعبة مجرد عرض تفاعلي يزيد التفاعل.

---

## ✅ المتطلبات
- **كمبيوتر** (ويندوز / ماك / لينكس) متصل بالإنترنت.
- **Node.js 18 أو أحدث**: https://nodejs.org (اختر «LTS»).
- **مفتاح EulerStream مجاني**: أنشئ حساباً في https://www.eulerstream.com (بدون بطاقة بنكية)
  واحصل على **API Key** من لوحة التحكم. الباقة المجانية (Community) كافية لبثّك:
  2,500 طلب/يوم و25 اتصال WebSocket.
- **TikTok Live Studio** (رسمي للكمبيوتر) أو **OBS Studio** للبث.

## 🚀 التشغيل (4 خطوات)

### 1) ثبّت المكتبات (مرة واحدة)
افتح «موجّه الأوامر / Terminal» داخل مجلد `tiktok-live-race` ونفّذ:
```bash
npm install
```

### 2) جهّز ملف الإعدادات
انسخ `config.example.json` إلى `config.json` واملأه:
```json
{
  "tiktokUsername": "اسمك_بدون_@",
  "signApiKey": "مفتاحك_من_eulerstream"
}
```

### 3) شغّل الأداة
```bash
npm start
```
سترى:
```
🌐 افتح لوحة السباق:  http://localhost:3000
✅ متصل بالبث المباشر (roomId: ...)
```

### 4) اعرضها فوق بثّك
- افتح **http://localhost:3000** في المتصفح ← تظهر لوحة السباق.
- في **TikTok Live Studio** أضف مصدراً: **Window Capture / التقاط نافذة** واختر نافذة المتصفح.
- ابدأ البث ← سيتفاعل مشاهديك بالتعليقات والهدايا.

> 💡 **مهم:** ابدأ البث المباشر من تطبيق TikTok **قبل** تشغيل الأداة، ليُقرأ البثّ بنجاح.

---

## 📺 العرض في TikTok Live Studio / OBS

**TikTok Live Studio (الأسهل):**
1. ثبّته وسجّل الدخول بحسابك، وابدأ بثّاً.
2. أضف **«Window Capture / التقاط نافذة»** واختر نافذة المتصفح (أو **«Screen Capture»**).
3. كبّرها وضعّها فوق الكاميرا، ثم ابدأ البث.

**OBS Studio:**
- أضف **Window Capture** لنافذة المتصفح، أو **Browser Source** بالرابط `http://localhost:3000`.

## ⚙️ تخصيص السلوك (في `config.json`)
| الإعداد | المعنى |
|---|---|
| `tiktokUsername` | اسم مستخدم TikTok (بدون @) |
| `signApiKey` | مفتاح التوقيع من EulerStream (مجاني) |
| `commentBoost` | قوة دفعة ذكر اسم دولة في تعليق |
| `likeBoost` | قوة دفعة اللايك |
| `giftBoostBase` | دفعة أساسية عند أي هدية |
| `giftBoostPerDiamond` | دفعة إضافية لكل ماسة |
| `giftMap` | (اختياري) ربط اسم هدية بدولة: `"Rose": "DZ"` |

---

## 🛠️ حل المشكلات
- **«فشل الاتصال بـ TikTok»**: تأكد أنك **تبث مباشر الآن**، وأن `tiktokUsername` (بدون @) و`signApiKey` صحيحان. الأداة تعيد المحاولة كل 30 ثانية.
- **«لم تُحدّد اسم مستخدم»**: أنشئ `config.json` بالاسم والمفتاح.
- **اللوحة لا تتحرك**: تأكد أن `http://localhost:3000` مفتوحة وأن هناك تعليقات/لايكات/هدايا فعلية تصل أثناء البث.
- **أيقونة العلم تظهر كمربّع**: استبدل الأعلام في `public/countries.json` بنصوص.
