# 🧗🪵 رجل الطريق الخشبي — بث TikTok تفاعلي

لعبة بثّ حقيقية: **رجل سمين مضحك** يصعد طريقاً خشبياً نحو القمة 🏆. كل **هدية حقيقية**
من مشاهديك تُسقط عليه مركّبة (دراجة 🏍️ / سيارة 🚗 / سيارة رياضية 🏎️ / شاحنة 🚚)
فيعود لنقطة الصفر أو يسقط في الهاوية! **وأنت تتحكم فيه بالكيبورد ليتفاداها** — وبدون هدايا
يكفي ألا يصطدم فيصل للقمة ويفوز.

> ⚠️ أداة غير رسمية تعتمد على `tiktok-live-connector` (مخالفة لشروط TikTok، على مسؤوليتك).
> تتطلب **مفتاح توقيع مجاني** من https://www.eulerstream.com (باقة Community مجانية للأبد).

---

## 🎮 التحكم (كيبورد الكمبيوتر)
| المفتاح | الوظيفة |
|---|---|
| **← →** أو **A / D** | تحريك يميناً/يساراً للتفادي |
| **↑** أو **W** | صعود أسرع |
| **↓** أو **S** | إبطاء/توقّف الصعود (للتفادي أفضل) |
| **🔄** (الزر) | إعادة الجولة |

> 💡 في **وضع المعاينة** (فتح اللعبة كملف/رابط بدون بث) يعمل **مساعد تفادٍ تلقائي** لترى اللعب،
> أما في **البث الحقيقي** فالتحكم بيدك أنت (الأسهم/WASD).

---

## 🧩 كيف تعمل؟
1. الرجل يصعد تلقائياً ببطء نحو القمة.
2. أي **هدية حقيقية** → مركّبة تسقط من الأعلى في اتجاهه.
3. أنت تحرّكه بالكيبورد ليتفاداها ← إن تفاداها سقطت في الهاوية وواصل الصعود.
4. إن أصابته → يسقط في الهاوية ويعود لنقطة الصفر (طرح +1).
5. اللايك → حجر صغير 🪨 يبطئه قليلاً.
6. إن وصل للقمة دون أن تُطرحه الهدايا → **يفوز 🏆** (احتفال + جولة جديدة).

## ✅ المتطلبات
- كمبيوتر + **Node.js 18+** (https://nodejs.org).
- **مفتاح EulerStream مجاني** (https://www.eulerstream.com).
- **TikTok Live Studio** أو **OBS** للبث.

---

## 🚀 التشغيل (4 خطوات)

### 1) ثبّت المكتبات (مرة واحدة)
```bash
npm install
```

### 2) جهّز `config.json` (انسخه من `config.example.json`)
```json
{ "tiktokUsername": "اسمك_بدون_@", "signApiKey": "مفتاحك_من_eulerstream" }
```

### 3) شغّل الأداة
```bash
npm start
```

### 4) اعرضها فوق بثّك
- افتح `http://localhost:3000/?name=اسمك` ← اضغط **«ابدأ البث 🎬»**.
- في **TikTok Live Studio / OBS** أضف **Browser Source** بالرابط أعلاه (الخلفية شفافة).
- تحكّم بالأسهم/WASD لتفادي المركّبات الساقطة ← المشاهدون يرسلون الهدايا لطرحك!

> 💡 ابدأ البث المباشر من TikTok **قبل** تشغيل الأداة.

---

## ⚙️ الإعدادات (`config.json`)
| الإعداد | المعنى |
|---|---|
| `tiktokUsername` | اسم TikTok (بدون @) |
| `signApiKey` | مفتاح التوقيع المجاني |
| `climbSpeed` | سرعة صعود الرجل (افتراضي 0.022 ≈ 45 ثانية للقمة بلا اصطدام) |
| `rockKnockback` | تأثير اللايك (حجر) |
| `giftMap` | (اختياري) ربط اسم هدية بنوع مركبة: `"Rose":{"e":"🏍️","n":"دراجة"}` |

---

## 🛠️ حل المشكلات
- **«فشل الاتصال»**: تأكد أنك **تبث مباشر الآن** وأن الاسم/المفتاح صحيحان (إعادة المحاولة تلقائياً كل 30ث).
- **لا تتحرك المركّبات**: افتح `http://localhost:3000` في المتصفح واضغط «ابدأ».
- **التحكم لا يستجيب**: انقر داخل نافذة اللعبة أولاً لتأخذ تركيز الكيبورد.

استمتع ببثّ مضحك وتفاعلي! 🎉
